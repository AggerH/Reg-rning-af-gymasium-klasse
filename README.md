Vi skal finde på et produkt som løser et problem inden for temaet oprydningen i en gymnasieklasse. Problemet kan være rat bredt siden det kan være alt som roder, det kan gå fra ikke at sette stole op til skrald der liger over helle gulvet. Teamet er også relevant fordi efter vær  eller næsten  vær time skiftere klassen klasse lokale. Det er nederen at komme til time hvor ens klasse ligger og flyder ud over det helle med uorden eller skrald. Desuden skal klasserne også rengøres og det kan kun ske hvis den er ryddet op og det behøves ikke at næves hvordan en klasse lokale ser ud hvis der ikke rengøres.
